URL Reference

Common params:

  • `target`
  • `autostart=0|1`
  • `showMs=0|1`
  • `renderer=classic|seven|flip|ring|splitflap`
  • `showInfo=0|1`
  • `infoText`
  • `infoPosition=tl|tr|bl|br`

Countdown params:

  • `duration`
  • `endMode=stop|loop|overtime`

Interval params:

  • `work`
  • `rest`
  • `rounds`
  • `finalMode=stop|loop`

Renderer params:

  • seven: `segmentGlow=0|1`
  • flip: `flipSpeed=slow|normal|fast`
  • ring: `ringThickness=4..32`, `ringTicks=0|1`
  • splitflap: `flapSpeed=slow|normal|fast`
